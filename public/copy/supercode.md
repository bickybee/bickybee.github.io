# The Project

[**SuperCode**](https://www.supercodeclub.com/) is a learn-to-code platform for kids. At the core of the platform is a 3D sandbox environment where anyone can create their own interactive 3D Worlds, coding them into games and interactive experiences by using Lua.

![Animated screen-caps of various parts of SuperCode: coding, playing games, building, and so on.](/media/supercode/hero.gif)

Built upon this sandbox environment are collections of narrative-driven educational games. Students meet the characters of the SuperCode Universe, learning about computer-science alongside them and solving problems with code.

# My Contributions

My primary responsibility, if I had to boil it down to just one thing, is to **deliver an enaging educational product**. I design and build interactive, educational experiences, working from the high-level product-planning and feature-definition phases down into the hands-on implementation.

As is typical for a start-up environment, I wear many hats, and don't find that any one title encompasses what I do. Here are some that I've tried on for size:

- **Educational Game Developer** --> Broad enough that it encompasses everything.
- **Product Engineer** --> Responsible for both defining product features and building them out.
- **Technical Game Designer** --> Responsible for both game design and technical implementation, a title familiar to games industry folks.

Below you'll find some of the specific projects I worked on.

## Code Missions

**Code Missions** is our first collection of educational games, currently in use by public school-boards, private schools, and STEM learning centers. Over 10,000 Missions have been completed by students (and their teachers)!

![An animated screen-cap of a Code Mission where players edit a while loop to pull weeds for an NPC.](/media/supercode/missions-loops.gif)
*Practicing while loop syntax to automating repetitive tasks for gardeners on a strange island.*

The Missions leverage an in-game, runtime Lua editor to intertwine coding with gameplay, as well as bespoke mini-games designed for different topics. I designed and developed over half of the 31 Missions in this collection from end-to-end, which encompasses:
- **Programming** --> coding gameplay logic in Lua.
- **Game design** --> building levels, structuring narratives, writing character dialogue.
- **Instructional design** --> designing challenges, building interactive analogies, writing instructional text.

![An animated screen-cap of a Code Mission where players rearrange data on a giant screen.](/media/supercode/missions-data.gif)
*Unscrambling espionage data as part of a fill-in-the-blanks activity, to help drive home the concept of data types.*

## SuperCode Saga

**SuperCode Saga** combines the core gameplay of Code Missions with a new game-mode called Activities, interactive tutorials that merge sandbox-style building with guided, story-driven learning.

![An animated screen-cap of a SuperCode Saga Activity where players add music speakers to a world in edit-mode, code them to play music, and enter the world to confirm that the music is playing, congratulated by dancing NPCs."](/media/supercode/activity.gif)
*The first Activity of the SuperCode Saga, set in a mysterious place called "The Rift" where reality can be altered and "hacked"!*

This time around, I oversaw development of the SuperCode Saga project as a whole, creating the high-level outline of games, writing briefs for each game, delegating responsibilities as we moved into production, and overseeing cohesiveness across the pipeline. I played a large role in improving the UX of the Activity system and defining the data architecture and APIs we would use internally to craft each Activity.

SuperCode Saga is currently in the process of being deployed to classrooms across North America!

## SuperCode Club

An incredible opportunity that I've had in this role is to work directly with users, the kids themselves. The **SuperCode Club** was an online coding class and community built upon SuperCode's sandbox-mode. I ran "Weekly Code Jam" sessions as a teacher for nearly 2 years, in tandem with my work on the above projects. My design decisions have been heavily informed by what I learned from this experience: witnessing first-hand how kids learn, how they play, and what motivates them to code!
